## Sobre

Funcoes auxiliares para deteccao de cores, processamento de imagens e extracao de features para navegacao autonoma e identificacao de marcadores.

---

## Modulos

| Modulo | Funcao |
|---|---|
| color_detection.py | Deteccao de cores por faixa HSV/LAB |
| filters.py | Filtros de imagem (gaussian, median, bilateral) |
| contours.py | Deteccao e processamento de contornos |
| calibration.py | Calibracao de cores e camera |
| morphology.py | Operacoes morfologicas (erode, dilate) |
